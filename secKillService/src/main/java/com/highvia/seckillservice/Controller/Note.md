秒杀：
════════════════════════════════════════
"总共100台iPhone"
↑
总数量，不是"一段时间内"

问题：
────────────────────────────────
怎么知道还剩多少？

只需要一个数字！
不需要知道"什么时候买的"！

Example:
────────────────────────────────
库存：100

User A买了1台 → 99
User B买了1台 → 98
User C买了1台 → 97
...

只需要：
stock = 97

不需要：
❌ User A什么时候买的
❌ User B什么时候买的
❌ 时间戳信息

因为秒杀不关心"时间窗口"！
只关心"总共还有多少"！
